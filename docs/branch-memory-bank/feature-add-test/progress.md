## 学んだこと

1. **テストの目的**
   - テストは実装の正しさを検証するためのものであり、期待値は実装の意図を正確に反映すべき

2. **テストの堅牢性**
   - 表示形式の細かな変更に影響されにくいテストが重要
   - 完全一致ではなく、必要な部分のみを検証する方が良い

3. **ヘルパー関数の重要性**
   - 共通のモックデータやアサーション関数を使用することで、テストの一貫性と保守性が向上する

4. **テスト駆動開発の原則**
   - テストが実装を導くべきであり、実装に合わせてテストを変更するのではなく、テストに合わせて実装を修正すべき
