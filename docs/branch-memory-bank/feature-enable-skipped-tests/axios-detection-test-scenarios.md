# AxiosDetectionStrategy テストシナリオ一覧

## 基本的なAxios呼び出し検出シナリオ

1. **直接メソッド呼び出し（axios.get等）を検出する**
   - `axios.get('/api/users')` のような標準的なaxiosメソッド呼び出しを検出
   - 戻り値としてGETメソッドのエンドポイント情報が正しく抽出される

2. **axios()関数直接呼び出しを検出する**
   - `axios('/api/users')` のようなaxios関数の直接呼び出しを検出
   - デフォルトでGETメソッドのエンドポイント情報が抽出される

3. **リクエスト設定オブジェクトを検出する**
   - `axios({ url: '/api/users', method: 'POST', data: { name: 'User' } })` のような
     設定オブジェクトを使用したリクエストを検出
   - URLとHTTPメソッドおよびパラメータが正しく抽出される

## インスタンス操作検出シナリオ

4. **インスタンスメソッド呼び出し（instance.get等）を検出する**
   - `const api = axios.create({ baseURL: 'https://api.example.com' }); api.get('/users')`
     のようなインスタンスメソッド呼び出しを検出
   - ベースURLとエンドポイントパスが正しく結合される

5. **インスタンス作成オプションを解析する**
   - `axios.create({ baseURL: 'https://api.example.com' })` からベースURLを抽出する
   - その他の設定（タイムアウト、ヘッダーなど）も適切に抽出する

6. **インスタンス直接呼び出しを検出する**
   - `apiInstance('/users')` のようなインスタンスの関数呼び出しを検出

## HTTPメソッド検出シナリオ

7. **axios.getメソッドを検出する**
   - GETリクエストが正しく識別される
   - パラメータがクエリパラメータとして抽出される

8. **axios.postメソッドを検出する**
   - POSTリクエストが正しく識別される
   - データがボディパラメータとして抽出される

9. **axios.putメソッドを検出する**
   - PUTリクエストが正しく識別される
   - データがボディパラメータとして抽出される

10. **axios.deleteメソッドを検出する**
    - DELETEリクエストが正しく識別される
    - パラメータが適切に抽出される

11. **axios.patchメソッドを検出する**
    - PATCHリクエストが正しく識別される
    - 部分更新データが適切に抽出される

## パラメータ抽出シナリオ

12. **axiosリクエスト設定からURLを抽出する**
    - 様々な形式のURL指定（文字列、設定オブジェクト、ベースURL+パスなど）から
      正しくURLを抽出する

13. **クエリパラメータを抽出する**
    - `axios.get('/api/users', { params: { page: 1, limit: 10 } })` から
      クエリパラメータを抽出する

14. **パスパラメータを抽出する**
    - `/api/users/:id` や `/api/users/{id}` からIDパラメータを抽出する

15. **リクエストデータからパラメータを抽出する**
    - `axios.post('/api/users', { name: 'User', email: 'user@example.com' })` から
      POSTボディパラメータを抽出する

16. **ヘッダーからパラメータを抽出する**
    - `axios.get('/api/users', { headers: { 'Authorization': 'Bearer token' } })` から
      認証情報を抽出する

## レスポンス処理検出シナリオ

17. **thenチェーンのレスポンス処理を検出する**
    - `axios.get('/api/users').then(response => response.data)` のような
      Promiseチェーンを使ったレスポンス処理を検出する

18. **async/await処理パターンを検出する**
    - ```
      async function fetchUsers() {
        const response = await axios.get('/api/users');
        return response.data;
      }
      ``` 
      のようなasync/awaitパターンを検出する

19. **エラーハンドリングパターンを検出する**
    - try/catchブロックやcatch()メソッドによるエラー処理を検出する

## インターセプター・設定検出シナリオ

20. **リクエストインターセプターを検出する**
    - `axios.interceptors.request.use(...)` のようなリクエストインターセプターを検出する
    - インターセプターからの追加パラメータ（認証トークンなど）を抽出する

21. **レスポンスインターセプターを検出する**
    - `axios.interceptors.response.use(...)` のようなレスポンスインターセプターを検出する
    - レスポンス変換処理を識別する

22. **デフォルト設定を検出する**
    - `axios.defaults.baseURL = 'https://api.example.com'` のようなデフォルト設定を検出する
    - プロジェクト全体のaxios設定を適切に処理する

## 統合・重複除去シナリオ

23. **検出結果を適切に統合する**
    - 異なる検出パターン（直接メソッド、インスタンス、設定オブジェクトなど）からの
      結果を適切に統合する

24. **重複するエンドポイント情報を適切にマージする**
    - 同じURLと同じHTTPメソッドによる複数のリクエストを検出した場合に、
      重複を除去しつつ使用箇所情報を保持する

25. **複数ファイルにまたがるaxios使用を関連付ける**
    - 異なるファイルでのaxiosインスタンス定義と使用を適切に関連付ける

## エラー処理・エッジケースシナリオ

26. **エラーハンドリングが機能することを検証する**
    - 検出中にエラーが発生した場合でも、適切に処理されログが出力される

27. **複雑なURLパスやテンプレートリテラルの解析を検証する**
    - `` axios.get(`/api/users/${userId}/posts/${postId}`) `` のような複雑なURLパスからも
      正しくパスパラメータが抽出される

28. **カスタムaxiosインスタンス名を検出する**
    - 変数名がaxiosを含まない場合でも、コンテキストからaxiosインスタンスを識別する
