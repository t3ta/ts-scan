# RTK Query型検出戦略の再設計

## プロジェクト目的

RTK Query の型システムを完全に活用し、静的型検出の精度と堅牢性を向上させることを目的とする。

## ユーザーストーリー

- **課題**: 現行の RTK Query エンドポイント検出メカニズムの型安全性が不十分
- **必要な機能**:
  1. 高精度な型レベルでのエンドポイント検出
  2. RTK Query の型システムを最大限に活用
  3. コンパイル時の型推論を強化

## 期待される動作

- エンドポイントの種別(Query/Mutation)を型レベルで正確に判定
- 静的型チェックによるランタイムエラーの削減
- 柔軟かつ堅牢な検出アルゴリズムの実装

## 技術的制約

- TypeScript の最新の型システムを活用
- ts-morph による静的解析
- @reduxjs/toolkit の型定義を完全準拠
