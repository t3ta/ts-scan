## タグの使用ガイドライン

1. **タグの命名規則**
   - 小文字のみを使用
   - 単語間はハイフンで接続
   - 簡潔で説明的な名前

2. **タグの付け方**
   - 各ドキュメントの先頭に記載
   - 複数のタグを使用可能
   - 最も関連性の高いタグを先頭に

3. **新しいタグの追加**
   - 既存のタグで表現できない場合のみ追加
   - このインデックスに追加することを忘れずに
   - 関連するタグとのグループ化を考慮

## タグの使用例

```markdown
# ドキュメントタイトル

tags: #primary-tag #secondary-tag #tertiary-tag

ドキュメントの内容...
```
