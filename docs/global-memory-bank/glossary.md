# 用語集

tags: #glossary #terms #definitions

## API関連用語

### エンドポイント
REST APIにおける個々のリソースやアクションへのアクセスポイント。URLとHTTPメソッドの組み合わせで定義される。

### ベースURL
APIのルートとなるURL。全てのエンドポイントの共通部分となる。
例: `https://api.example.com/v1`

### HTTPメソッド
- GET: リソースの取得
- POST: リソースの作成
- PUT: リソースの更新（全体）
- PATCH: リソースの更新（部分）
- DELETE: リソースの削除

## 検出戦略関連

### 検出戦略（Detection Strategy）
特定のパターンやフレームワークに特化したAPI使用箇所の検出ロジック。

### パターン検出器（Pattern Detector）
コード内の特定のパターンを検出するための専門化されたコンポーネント。

### エンドポイントビルダー（Endpoint Builder）
検出されたAPI使用箇所から一貫した形式でエンドポイント情報を構築するコンポーネント。

## フレームワーク固有用語

### RTK Query
Redux Toolkit Queryの略。Reduxエコシステムにおける効率的なデータフェッチング・キャッシングソリューション。

### createApi
RTK Queryにおいて、APIスライスを定義するための関数。エンドポイントとその振る舞いを定義する。

### injectEndpoints
既存のRTK Query APIスライスに新しいエンドポイントを追加するための機能。

### Axios
Promise ベースのHTTPクライアント。ブラウザとNode.jsで動作する。

## コード解析関連

### AST（Abstract Syntax Tree）
ソースコードの構文構造を表現する木構造のデータ形式。

### トラバーサル（Traversal）
ASTのノードを巡回して情報を収集または処理を行うこと。

### 型推論（Type Inference）
明示的な型注釈がない場合に、コンテキストから型を決定するプロセス。

## アーキテクチャ用語

### サービスロケータ（Service Locator）
依存性の中央管理を行うコンポーネント。サービスの登録と解決を担当。

### 戦略パターン（Strategy Pattern）
アルゴリズムをカプセル化し、実行時に切り替え可能にするデザインパターン。

### ファサードパターン（Facade Pattern）
複雑なサブシステムに対するシンプルなインターフェースを提供するパターン。

## レポーティング関連

### JSON形式
構造化されたデータを表現するためのテキスト形式。マシンリーダブル。

### Markdown形式
人間が読みやすい形式のテキストフォーマット。リッチテキスト表現が可能。

### 統計情報
- エンドポイント使用頻度
- HTTPメソッド分布
- パターン別検出数
